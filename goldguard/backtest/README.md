# backtest/ — Event-Driven Backtester & Walk-Forward Harness

## Invariants

- **Same code path as live.** The backtester calls the real
  `Strategy.generate`, the real `RiskEngine.evaluate`, and the real
  `DrawdownLadder`. No risk rule is re-implemented or relaxed here.
- **Costs are mandatory** and cannot be disabled: commission per side
  (default $1.24 MGC) plus slippage (1 tick normal, 4 ticks on event days).
- The broker-side stop is simulated intrabar every day; the weekend flatten
  (Friday 16:00 ET) is enforced.
- Walk-forward: train 3y / test 1y, rolled annually; only out-of-sample
  test segments are reported.
- `validation_report.md` (the §9 phase-gate artifact) is generated by
  `python -m goldguard.backtest.report --bars <continuous.csv>`. Reports run
  on the synthetic fallback series are stamped **NOT VALID FOR THE PHASE
  GATE** — supply a real back-adjusted continuous contract and document the
  vendor and roll method.
